# Privacy Policy for AutoTok

**Effective Date:** October 20, 2026

## 1. Information We Collect
AutoTok is an internal creator workflow tool. We only process:
- User authorization credentials (e.g., OAuth 2.0 access tokens) required to interact with the TikTok API.
- Carousel media files (JPEG images) and localized text captions for posting purposes.

## 2. How Information is Used
The information collected is used solely to:
- Authenticate and communicate with the TikTok API on behalf of the user.
- Upload media and schedule photo carousels to the designated TikTok account.

## 3. Data Storage & Security
- All sensitive tokens and credentials are encrypted or stored locally within the user's controlled environment (.env / SQLite).
- We do not transmit or sell user credentials or personal data to third parties.

## 4. Third-Party Services
AutoTok connects to TikTok via the official TikTok Developer Platform. For information on how TikTok processes your data, please refer to [TikTok's Privacy Policy](https://www.tiktok.com/legal/privacy-policy).

## 5. Contact
For any privacy inquiries, please contact the repository administrator.
